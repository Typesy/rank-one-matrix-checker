# Rank-one matrix checker

An exact research tool for finite-field matrix spaces generated by rank-one matrices. A **good set** is an independent rank-one basis whose span contains no additional rank-one directions. The main examples use F2, F3, F4 and F5.

## Windows: start here

1. Click **Code → Download ZIP** on GitHub.
2. Right-click the downloaded ZIP and choose **Extract All**. Open the extracted folder.
3. Install **Python 3.12** from [python.org](https://www.python.org/downloads/windows/), keeping the Python launcher and Tcl/Tk options selected.
4. Double-click **Setup Checker.bat**. Setup downloads the required mathematical library. Wait for “Ready.”
5. Double-click **Open Checker.bat** whenever you want to use the checker.

After setup, computations run locally. You do not need a GitHub account. Keep the extracted folder together; opening a launcher inside an unextracted ZIP will not work.

## First demonstration

1. In **Examples**, select **Three generators over F2 — passes**.
2. Choose **Actions → Check matrices**. Expect **PASS**, three generators and no extra rank-one directions.
3. In **Examples**, select the corresponding F3 triple. Check again. Expect **FAIL**, with an explicit extra rank-one matrix and coefficients.
4. Choose **Research → Rank counts** for the rank distribution, or **Research → Factor analysis** for the paired factor data.
5. Use **Save result** to save a JSON certificate. **Replay saved certificate** checks that saved evidence independently.

The **Research**, **View**, **Examples** and **Check method** menus provide alternatives to the on-screen buttons. Ctrl+Enter checks a set on Windows; Command+Enter does so on macOS.

## Research views

- **Check**: editable matrices and five exact/comparison checking methods. Use a blank line between matrices. F4 labels are 0, 1, 2 = alpha and 3 = alpha+1 with alpha² = alpha+1; arithmetic is not modulo 4.
- **Bounds / search**: fix q, rows and columns; inspect proved bounds, load verified constructions, or run a time-limited search. Optional k is the target size. The parameter dialog is available under **Research → Set research parameters**.
- **Compare**: compare spaces under the same invertible row and column changes. Reordering and nonzero rescaling of basis generators are allowed. Square transpose and a common Frobenius automorphism are optional and stated separately. Equivalent inputs include explicit transformations.
- **Classes**: inspect known complete small classifications, enumerate a small finite parameter domain, or group only the examples you supply. Those scopes have different labels.
- **Explain**: a concise explanation to use in a demonstration.

**PASS establishes an example and hence a lower bound.** It does not by itself establish the largest possible size. **EXACT** requires a matching upper bound or completed exhaustive exclusion. **GAP**, **PARTIAL** and **INCONCLUSIVE** mean what they say. Stop cancels the active computation. Large equivalence and exhaustive searches can remain incomplete.

## macOS / Linux / terminal

Use a Python 3.12 installation with Tk. From the extracted folder:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install '.[test]'
.venv/bin/python -m rankone.gui
.venv/bin/python -m pytest -q
```

On Windows the corresponding test command is `.venv\Scripts\python.exe -m pytest -q` after installing `.[test]`. CLI commands are available through `rank-one-check --help` in the environment. The exact dependency used is galois 0.4.11.

## Checking and certificates

The default method writes the span as homogeneous linear equations. For each normalized left factor u, it solves for all right factors v for which uv-transpose lies in the span. Completing these fibres covers every rank-one member. A separate implementation replays the certificate. Failures include a concrete wrong-rank generator, a nontrivial zero combination, or an extra rank-one matrix with coefficients. Work limits never produce an unsupported successful decision.

Equivalence uses A → PAQ with shared invertible P and Q, and optional square transpose / common Frobenius. A completed positive comparison supplies replayable transformations; incomplete searches do not claim inequivalence. Grouping a collection is not a complete orbit classification of all possible sets.

This is research software, with independent algorithms and regression tests; it is not a formally verified proof assistant. The included numerical bounds distinguish proved maxima from unresolved intervals. See `VERIFICATION.md` for the actual release checks and platform limits.
